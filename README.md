# 📊 Power BI Sales Dashboard

This project is a fully interactive **Power BI Sales Dashboard** created to analyze and visualize business performance in a simple and meaningful way. The dashboard provides clear insights into **Sales, Profit, and Units Sold** using attractive charts, KPIs, and filters that help users understand business trends quickly.

The dashboard is divided into three main reports:

* **Sales Report** – Shows overall sales performance, monthly sales trends, product-wise sales, segment analysis, and discount band impact.
* **Profit Report** – Helps track profit growth, identify profitable products, and analyze how discounts affect profitability.
* **Units Sold Report** – Displays product demand, sales quantity trends, and segment-wise unit distribution.

The dashboard also includes:

* 📌 Interactive slicers for country-based filtering
* 📈 Dynamic charts and trend analysis
* 🎨 Modern dark-themed UI design
* 📊 KPI cards for quick business overview

This project was built to improve data analysis and business decision-making by transforming raw sales data into easy-to-understand visual insights.

## 🛠️ Technologies Used

* Power BI Desktop
* DAX Functions
* Data Modeling
* Interactive Visualizations

## 🎯 Key Insights

* Identify top-performing products and segments
* Track monthly business growth
* Analyze discount impact on sales and profit
* Compare performance across countries
